## 前置需求

### 系統需求

- **作業系統**: Linux (推薦 Ubuntu 20.04+) 或 macOS
- **Docker**: 20.10.0 或更高版本
- **Docker Compose**: 2.0.0 或更高版本
- **記憶體**: 最少 8GB RAM（建議 16GB）
- **儲存空間**: 至少 20GB 可用空間

### 必要工具

```bash
# 檢查 Docker 版本
docker --version

# 檢查 Docker Compose 版本
docker-compose --version

# 檢查 Git
git --version
```

## 環境設定

### 步驟 1: 複製專案

```bash
# 複製專案到本地
git clone https://github.com/trionnemesis/aiops-rag-system.git
cd aiops-rag-system
```

### 步驟 2: 設定環境變數

```bash
# 複製環境變數範本
cp .env.example .env

# 編輯 .env 檔案
nano .env  # 或使用您偏好的編輯器
```

**重要設定項目**：

1. **GEMINI_API_KEY** (必需)
   - 前往 [Google AI Studio](https://aistudio.google.com/app/apikey) 申請
   - 或使用 [MakerSuite](https://makersuite.google.com/app/apikey)
   - 將取得的 API Key 填入 `.env` 檔案

2. **服務主機名稱**
   - Docker 環境中，保持預設值即可：
     - `OPENSEARCH_HOST="opensearch"`
     - `PROMETHEUS_HOST="prometheus"`
     - `REDIS_URL="redis://redis:6379"`

3. **環境標識**
   - 首次部署建議使用：`ENVIRONMENT="development"`
   - 生產環境改為：`ENVIRONMENT="production"`

### 步驟 3: 驗證設定

```bash
# 檢查 .env 檔案是否正確
cat .env | grep -E "GEMINI_API_KEY|OPENSEARCH_HOST|REDIS_URL"

# 確保 GEMINI_API_KEY 已設定
if grep -q "your-gemini-api-key-here" .env; then
  echo "警告: 請設定 GEMINI_API_KEY"
  exit 1
fi
```

## 服務部署

### 步驟 1: 建置並啟動服務

```bash
# 建置並啟動所有服務（背景執行）
docker-compose up -d --build

# 查看服務狀態
docker-compose ps

# 等待所有服務健康檢查通過（約需 1-2 分鐘）
echo "等待服務啟動..."
sleep 60

# 檢查服務健康狀態
docker-compose ps | grep -E "(healthy|running)"
```

### 步驟 2: 確認服務運行狀態

檢查各項服務是否正常運行：

```bash
# 檢查 API 服務
curl -f http://localhost:8000/health || echo "API 服務尚未就緒"

# 檢查 OpenSearch
curl -f http://localhost:9200/_cluster/health || echo "OpenSearch 尚未就緒"

# 檢查 Prometheus
curl -f http://localhost:9090/-/healthy || echo "Prometheus 尚未就緒"

# 檢查 Redis
docker-compose exec redis redis-cli ping || echo "Redis 尚未就緒"
```

### 步驟 3: 查看服務日誌

如果有服務未正常啟動，查看日誌以診斷問題：

```bash
# 查看所有服務日誌
docker-compose logs

# 查看特定服務日誌
docker-compose logs app
docker-compose logs opensearch

# 持續追蹤日誌
docker-compose logs -f app
```

## 初始化流程

### 步驟 1: 初始化 OpenSearch 索引

```bash
# 執行 OpenSearch 初始化腳本
docker-compose exec app python scripts/init_opensearch.py

# 預期輸出：
# [INFO] Connecting to OpenSearch...
# [INFO] Creating index: aiops-knowledge-base
# [INFO] Index created successfully
# [INFO] Loading sample documents...
# [INFO] Successfully indexed X documents
```

### 步驟 2: 建立向量索引

```bash
# 建立 KNN 向量索引
docker-compose exec app python scripts/build_knn_index.py

# 預期輸出：
# [INFO] Initializing KNN index builder...
# [INFO] Creating KNN index with HNSW algorithm...
# [INFO] Index mapping created successfully
# [INFO] Building vectors for documents...
# [INFO] Successfully indexed X documents with vectors
```

### 步驟 3: 驗證索引建立

```bash
# 檢查索引狀態
curl -X GET "http://localhost:9200/_cat/indices?v" | grep aiops

# 檢查文件數量
curl -X GET "http://localhost:9200/aiops-knowledge-base/_count"

# 執行測試搜尋
docker-compose exec app python scripts/test_knn_search.py
```

## 常見問題

### Q1: OpenSearch 無法啟動

**症狀**: OpenSearch 容器不斷重啟

**解決方案**:
```bash
# 檢查記憶體限制
docker-compose logs opensearch | grep "memory"

# 增加 Docker 記憶體配置
# macOS: Docker Desktop > Preferences > Resources
# Linux: 檢查系統 vm.max_map_count
sudo sysctl -w vm.max_map_count=262144
```

### Q2: API 服務連接 OpenSearch 失敗

**症狀**: API 日誌顯示 "Connection refused"

**解決方案**:
```bash
# 確認服務名稱解析
docker-compose exec app nslookup opensearch

# 檢查環境變數
docker-compose exec app env | grep OPENSEARCH

# 重啟服務
docker-compose restart app
```

### Q3: 向量索引建立失敗

**症狀**: build_knn_index.py 執行錯誤

**解決方案**:
```bash
# 檢查 Gemini API Key
docker-compose exec app env | grep GEMINI_API_KEY

# 手動測試 API 連線
docker-compose exec app python -c "
from src.config import settings
print(f'API Key 已設定: {bool(settings.gemini_api_key)}')
"

# 重新執行初始化
docker-compose exec app python scripts/init_opensearch.py
docker-compose exec app python scripts/build_knn_index.py
```

### Q4: 服務啟動順序問題

**症狀**: 某些服務在依賴服務前啟動

**解決方案**:
```bash
# 完全停止所有服務
docker-compose down

# 依序啟動核心服務
docker-compose up -d opensearch redis
sleep 30

# 啟動監控服務
docker-compose up -d prometheus
sleep 10

# 最後啟動應用服務
docker-compose up -d app

# 啟動其他服務
docker-compose up -d
```
